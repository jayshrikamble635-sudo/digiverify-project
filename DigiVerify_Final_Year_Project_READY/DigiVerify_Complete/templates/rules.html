How decisions are assigned

The current engine uses OCR text, document-number patterns, image properties, OCR confidence, and duplicate-image matching.

APPROVED — screening passedRisk ≤ 20 and number pattern found
REVIEW REQUIRED — needs human reviewUncertain OCR or incomplete checks
REJECTED — configured high-risk ruleRisk ≥ 60, explicit sample/fake marker, or exact duplicate

Document number patterns

  • Aadhaar: 12 digits grouped as 4-4-4
  • PAN: 5 letters, 4 digits, 1 letter
  • Passport: 1 letter followed by 7 digits
  • Voter ID: 3 letters followed by 7 digits
  • Driving Licence: state code, RTO code and number sequence
These are format heuristics only. A valid-looking number does not prove that a document exists or belongs to the uploader. Government verification requires an authorized official integration.
